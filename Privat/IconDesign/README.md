# Barcode-Icon

Erstellt mit dem eingebauten Imagegen-Werkzeug. Die Projektkärtchen bleiben unverändert.

Prompt: Das vom Nutzer beigefügte Bild als genaue Stilvorlage verwenden. Ein plastischer, abgerundeter, tiefschwarzer Glasbutton wie bei Mathe Kids, mit gewölbter Front, glänzendem Rand und sichtbarer Tiefe. Dezente diagonale Lichtreflexion, genau vier verchromte Audi-Ringe, weißer Barcode und leuchtend roter Scanstrahl. Ohne Schrift, Bühne oder weitere Objekte. Zentrale Komposition für Android-Symbole.

`barcode-gloss-master.png` ist die hochauflösende Vorlage. Ab Version 126 hat das Glasquadrat einen helleren silbernen Rand und sichtbarere Tiefe auf vollständig schwarzem Hintergrund.

`export-icons.ps1` (Windows) und `bash Privat/IconDesign/export-icons.sh` (Cloud mit ImageMagick) skalieren dieselbe Vorlage für Web, Apple und Android. Separate maskierbare Web-Icons haben zusätzlichen Sicherheitsabstand für runde Darstellung. Android erhält einen adaptiven Vordergrund sowie Icons für Android 7. Die PowerShell-Version erzeugt außerdem `icon-vorschau.png`.
